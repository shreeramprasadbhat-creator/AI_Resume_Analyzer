# AI Resume Analyzer

An AI-powered Resume Analyzer built with Python, Streamlit, and Google Gemini.

## Features
- Upload PDF resumes
- Extract resume text
- Detect technical skills
- Generate resume score
- AI-powered feedback using Gemini
- Suggest improvements and job roles

## Tech Stack
- Python
- Streamlit
- Google Gemini API
- pdfplumber
- python-dotenv

## Installation

git clone <your-repo-url>

pip install -r requirements.txt

streamlit run app.py
